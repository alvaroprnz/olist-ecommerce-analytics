# olist-ecommerce-analytics
Este proyecto analiza la operación del marketplace Olist (2016–2018) para diagnosticar cómo el desempeño logístico y los retrasos en las entregas impactan directamente en la satisfacción del cliente (Rating de 1 a 5 estrellas).

SQL Server: Limpieza de datos, ajuste monetario y creación de la vista maestra.

Python: Conexión a la base de datos, análisis exploratorio (EDA), percentiles y matriz de correlación.

Power BI: Diseño del dashboard ejecutivo interactivo y modelado de indicadores en DAX.

Analisis de mas de 100.000 datos reales de cientes de Olist
